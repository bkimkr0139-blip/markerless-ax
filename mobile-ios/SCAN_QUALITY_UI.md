# 스캔 품질·누락 실시간 모니터링 UI

얼굴/지문 등록처럼 "빠진 곳 없이, 잘 찍혔는지"를 눈으로 보면서 스캔한다. 공간·시설물·사물 스캔이 같은 부품(`ScanQualityKit.swift`, `ScanQualityViews.swift`)을 쓴다.

## 구성
| 요소 | 무엇을 보여 주나 |
|---|---|
| **품질 링 (QualityRing)** | 둘러 채우는 링 지도. 칸 색: 빨강=비어 있음, 주황=찍혔지만 품질 낮음/프레임 부족, 초록=양호, 민트=좋음. 지금 보는 방향 쐐기, 다음 목표 칸 맥박, 가운데 진행률 |
| **실시간 품질 바 (LiveQualityBar)** | 지금 이 순간 촬영 상태 좋음/주의/나쁨 + **이유**(너무 빠름·흔들림·너무 가까움/멂·깊이 불확실·어두움·추적 불안) + 바로 할 행동 + 거리(m) |
| **가장자리 화살표 (EdgeGuide)** | 빠진 곳이 화면 밖이면 좌/우 화살표와 각도, 천장/바닥이면 위/아래 안내 |
| **완료 전 점검 (ScanReviewView)** | 촬영 완료 직전, 펼친 지도 + 문제 목록(비어 있음/품질 낮음) + [여기 다시]·[부족한 곳 다시 스캔]·[그대로 진행]. 권장 80% 미만이면 경고 |
| **촉각 (ScanHaptics)** | 칸이 양호로 올라갈 때 가볍게, 품질이 나빠질 때 경고, 목표/링 완성 때 성공 |

## 칸 상태 규칙
`비어 있음`: 0프레임 · `품질 낮음`: 프레임 < need 또는 평균 품질 < 0.5 · `양호`: need 이상 & 평균 ≥ 0.5 · `좋음`: need+1 이상 & 평균 ≥ 0.75.
프레임 품질 = 속도·흔들림·거리·깊이 신뢰도·유효 깊이 비율·밝기·추적의 곱(0~1). 표시는 EMA와 연속 확인으로 깜빡임을 줄이고, 나빠짐은 빨리·좋아짐은 천천히 반영.

## 공간 스캔 (링: 벽 바깥 / 천장 / 바닥 안쪽)
- 시선 방위 24섹터 × 3띠, 한 번 비출 때 시야각(±FOV·0.3)의 이웃 섹터도 낮은 가중으로 채움(파노라마처럼 한 번에 여러 칸).
- 점검 트리거: 전체 진행도 <80% **또는** 벽에 빈/낮은 칸 **또는** 바닥·천장 링 <50%. (바닥·천장 작은 구멍만으로는 자동으로 띄우지 않음 — 점검 화면 목록에는 보임, 수동 [점검] 버튼으로 언제든 열기)
- [부족한 곳 다시 스캔]: 목표 구간 지정 → 링 맥박 + 화살표 → 채워지면 자동 해제("채워졌어요").

## 사물 스캔 (링: 바깥=옆·비스듬, 안쪽=윗면)
- 사물 둘레 방위 24섹터(시작 위치=0°, 왼쪽으로 증가). 위치를 아는 경계 근처 표본만 이웃에 0.7배로 전달(한 번도 안 본 섹터가 채워지지 않게).
- 점검: 둘레 <90% 또는 품질 낮은 칸이 있으면 [분리 확인] 전에 표시. 면 이름은 앞/왼쪽/뒤/오른쪽(+앞·뒷면 조합), 윗면.

## 실기기에서 조정할 값 (모두 초기값)
- 거리 이상 범위: 공간 0.6~3.5m, 사물 0.4~1.2m. 속도 한계: 공간 0.35m/s·0.8rad/s, 사물 0.25m/s·0.7rad/s.
- 칸 채움 need(공간 3샘플≈0.3초, 사물 3), 이웃 채움 폭/가중, 점검 임계(80%/90%/50%), 깊이 신뢰도·유효비율 기준.
- 밝기: ARKit `ambientIntensity`는 실제 lux가 아니라 "어두움" 경고가 드물 수 있다.
- 비용: 공간 10Hz 샘플링 + 중앙 깊이 창 통계 + SwiftUI 재그리기 — 프레임 저하/발열을 볼 것.

## 검증 상태
- 순수 로직: swiftc 하네스 4종 ALL OK (`Tools/scanquality_check.swift`, `spacescan_quality_check.swift`, `objscan_quality_check.swift`, `spacescan_logic_check.swift`).
- 렌더링: 시뮬레이터에서 컴포넌트 갤러리(`-qualitygallery`)·점검 화면(`-qualityreview`)을 실행 인자로 열어 확인(일반 실행에는 영향 없음).
- **실기기(ARKit/LiDAR) 동작은 미검증** — 시뮬레이터에는 카메라·LiDAR가 없다.
