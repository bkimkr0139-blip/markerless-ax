# PRODUCTION_GAP.md — PoC에서 운영까지 남은 격차

## 반드시 (운영 전)
1. **실기기·실측 검증**(GROUND_TRUTH.md): half-pixel 규약, intrinsics 환산, RoomPlan 정렬, 드리프트, 임계값 튜닝. 지금 수치는 합성/공개 데이터 기준.
2. **인증 체계**: 모바일은 단일 API 키 → 사용자·단말별 토큰, 키 회전, 관리자 2단계 인증, 세션 정책. (적용됨: 비밀번호 정책, 기본 비밀번호 변경 강제, 로그인 시도 제한 기존, 감사 로그)
3. **데이터 인프라**: SQLite → PostgreSQL/PostGIS 이관(현재 DB 건수 3공간·7자산·16검수·10이슈와 이관 후 대조), 객체 스토리지(원본 RGB/Depth/월드맵과 파생 GLB 분리), 업로드 ACL·프로젝트별 보존기간·용량/비용 상한, **자동 백업**(`tools/backup.sh`는 수동 스크립트).
4. **재구성 워커 분리**: 현재는 API 프로세스 안의 스레드 1개(동시성 1). 큐(재시도·복구), 메모리/CPU/열 상한, 별도 워커 프로세스·장애 격리.
5. **개인정보·산업보안**: 실내 사진의 사람·화면·문서 가림 처리, GPS 보관 정책, 외부 AI로 원본 전송 금지(현재 모든 AI는 로컬 ONNX 추론 — 원본이 밖으로 나가지 않음).
6. **서버 이중화**: 개발 Mac 단일 서버(frp). 컨테이너/클라우드, TLS 정책, IP 제한, 모니터링·알림.
7. **git 이력**: 저장소에 커밋이 하나도 없다(변경 이력 보호 없음). 체크포인트 커밋과 브랜치 전략, CI(테스트+벤치마크 회귀 게이트).

## 기능 격차
- 멀티밴드 블렌딩·텍스처 초해상, 거울/유리 처리 검증, 창/문 상태 인식(AI), 계단·층간 연결, 지붕/외부 사진 기반 외관 텍스처(외부 촬영 시), IFC/Revit에서 DESIGN 지오메트리 자동 추출, 센서 기반 L3(IoT·CMMS) 동기화, L5 제어는 별도 안전 승인 과제.
- 모바일: 오프라인 모드, 백그라운드 URLSession 업로드, 촬영 가이드 AR 링, Android/ARCore.
- 관리자 웹: 트윈 주석 서버 저장, 세션/재구성 진행 화면(API는 있음), 검수 이력 필터 deep link.
