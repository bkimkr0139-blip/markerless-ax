# QUALITY_TECHNIQUES.md — 스캔 정밀도·3D 모델 품질 기법: 시도·측정·채택 기록 (2026-10-11)

원칙: **효과가 측정으로 입증된 기법만 기본값으로 켠다.** 입증 못 한 것·오히려 나빠진 것은 끄고 이유를 남긴다.
측정은 (a) 정답을 아는 합성 방(`tools/twin_bench.py`)과 (b) 실제 RGB-D(NYU Depth V2, `tools/depth_prior_bench.py`)로 했다.
**실기기(iPhone LiDAR) 실측은 아직 없다** — 아래 수치는 실기기 정확도가 아니다(`docs/GROUND_TRUTH.md`).

## 1. 채택(기본 켜짐) — 효과 입증
| 기법 | 무엇을 | 측정 결과(합성) | 코드 |
|---|---|---|---|
| **half-pixel 규약 통일** | 역투영과 TSDF 투영의 픽셀 중심 규약 불일치 수정 | 완벽 포즈에서 프레임-모델 잔차 5~14mm → 정상화(3m에서 ~2cm 오차원인 제거) | `camera.py` |
| **평면 오프셋 정밀화** | 벽 평면 위치를 면적 가중 중앙값으로 | 방 치수 오차 60~85mm → 4~5mm | `structure.py` |
| **포즈 그래프 최적화(루프 클로저)** | 키프레임 ICP 루프 간선 + 주행 간선, 정보행렬로 평면 퇴화 처리 | 드리프트 2mm/프레임: 벽 층 번짐 **86.5 → 5.2mm**, 4mm/프레임: **176.7 → 18.0mm**. 드리프트 없으면 채택 안 함(무해) | `pose_graph.py` |
| **메시 정규화** | 벽·바닥·천장 정점을 정밀 피팅한 평면에 스냅, 코너는 교점, 나머지 Taubin 평활 | 구조면 평균 평면편차 2.8 → 1.0mm(잡음 3mm), 3.4 → 1.1mm(8mm); 평면오차 1.2 → 0.25mm; 박스 사물 높이 보존(0.800m). 원본 `observed.glb`는 보존 | `refine_mesh.py` |
| **텍스처 보정** | 프레임·채널별 노출/WB 이득(중앙값 추정) + 선명도 가중 + 2대역 블렌딩(저주파 평균 + 고주파 최선 뷰) | 노출·WB ±35% 변동에서 면 내 색 얼룩 8.08 → 6.17 (−24%), 균일 노출에서도 6.23 → 5.59 | `texture.py` |
| **AI 의미 분할로 사람 제외** | SegFormer-B0(ADE20K)로 사람 마스크 → 깊이 0·텍스처 제외 | 움직이는 사람이 남기던 방 안 유령 표면 **4.24㎡ → 0㎡** | `semantic_mask.py` |
| **iOS 촬영 품질** | 선명도(라플라시안) 기반 최선 프레임 선택, 정지 시 깊이 5장 신뢰도 가중 평균(σ≈1/√5), 열 상태 자동 일시정지, 선택형 4K 정지 사진 | 순수 로직은 swiftc 하네스로 검증(ALL OK), 앱 빌드 성공. **실기기 미검증** | `mobile-ios/CAPTURE_QUALITY.md` |
| **웹 투어 렌더링** | Unlit+sRGB+이방성 필터, 점진 LOD(mobile→web→full)+텍스처 예산, 감쇠 걷기·벽 미끄러짐·자동 투어·사진 모드, 성능 가드 | 헤드리스 Chrome 점검 오류 0, 재질·LOD 전환·예산 축출 확인 | `twin3d.js` |

## 2. 시도했지만 기본 꺼짐 — 효과 입증 실패 (정직한 기록)
| 기법 | 결과 | 결정 |
|---|---|---|
| **RGB 가이드 깊이 업샘플** (실제 RGB-D 60장) | 관측 픽셀 AbsRel 0.0059 vs 쌍선형 0.0052, 경계 0.0685 vs 0.0659 — **이득 없음** | 끔(`guided=False`) |
| **AI 단안 깊이로 LiDAR 빈 곳 채우기** (Depth Anything V2, 전역/국소 아핀 정합) | LiDAR 유효 범위 안의 구멍: AI 7.4% vs **단순 최근접 5.8%** (δ1 93.7% vs 93.9%) — AI가 낫지 않음. 범위 밖(>4m) 구멍: AbsRel 25~30%, δ1 34~46% — **신뢰 불가** | **지오메트리에 쓰지 않음**. 모듈(`depth_prior.py`)은 실험용으로 보관, 쓴다면 INFERRED 레이어로만 |
| **프레임-모델 자세 보정(KinectFusion식)** | 평면 위주 방에서 평면 위로 미끄러져 기준선보다 약간 나빠짐(드리프트 ±1cm: 층 번짐 13.9 → 16.7mm) | 끔(`track_poses=False`). 포즈 그래프가 대신 해결 |
| **거울·유리·창 AI 마스크** | 거울을 찾지만 경계가 거칠어 옆 사물(변기·수건)까지 번짐 → 커버리지 손실 위험 | 옵션(`mask_reflective=False`), 실기기 검증 후 켬. 작은 조각 노이즈는 크기 필터로 제거 |

## 3. 아직 하지 않은 것 (정직)
- **멀티밴드 라플라시안 블렌딩 / 텍스처 초해상 / 포토메트릭 정제**: 2대역 블렌딩까지만.
- **AI 생성형 텍스처·형상 채우기(인페인팅)**: 미관측은 만들어 채우지 않는다(회색+마스크, INFERRED 평면 패치). 보이지 않는 면을 AI로 그려 넣으면 “실제 관측처럼 보이는” 위험이 있어 의도적으로 제외.
- **3D Gaussian Splatting / NeRF**: 렌더 표현 연구 항목. 정밀 검측의 기하 기준으로 쓰지 않는다(지시서 §4.1). 실사 질감 투어는 텍스처 메시로 제공.
- **스크린드 포아송 재구성**(Open3D 없음): TSDF+마칭큐브 사용.
- **실기기 LiDAR 데이터로 임계값 튜닝**: 선명도·정지·마스크·정렬 임계값은 모두 합성/공개데이터 기준 초기값.

## 4. 재현
```
tools/fetch_models.sh [--depth]            # AI 모델(선택)
.venv/bin/python tools/twin_bench.py       # 합성: 기하·텍스처·재방문·드리프트·정규화·성능
.venv/bin/python tools/depth_prior_bench.py --n 60   # 실제 RGB-D(NYU)로 깊이 기법 비교 (데이터: HF sayakpaul/nyu_depth_v2 val)
```
