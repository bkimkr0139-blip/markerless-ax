# FAILURE_CASES.md — 알려진 실패 사례와 시스템의 대응

| 상황 | 영향 | 시스템 대응 | 사용자가 할 일 |
|---|---|---|---|
| 거울·유리·창 | 반사 깊이/영상으로 가짜 표면·가짜 방 | 기본 비활성(`mask_reflective`) — 경계 번짐 위험. 깊이 무효 구멍은 미관측 | 큰 거울/유리는 수동 확인, 필요 시 가리고 촬영 |
| 움직이는 사람·물체 | 유령 표면·색 번짐 | AI 분할로 사람 제외(검증: 유령 4.24→0㎡), 앱에서 "방금 구간 제외" 버튼 | 사람이 지나간 구간 제외/재촬영 |
| 어둡거나 반사 심한 면(검은 장비, 광택) | LiDAR 무효 → 구멍 | 미관측으로 남기고 커버리지·히트맵에 표시, INFERRED 평면 패치는 구조면에만 | 각도를 바꿔 재촬영 |
| 장시간 촬영의 VIO 드리프트 | 벽이 겹겹이 번짐 | 포즈 그래프 루프 클로저(합성 86→5mm). 루프가 부족하면 채택 안 함 | 출발점으로 돌아와 겹치게 촬영 |
| 월드맵 재위치 실패(UNREGISTERED) | 기존 공간과 좌표 불일치 | 자동 병합 금지(API 409), 새 세션으로만 처리 | 관리자 수동 정합 확인 후 병합 |
| 대칭 방(직사각형, 문·창 단서 없음) | 세션/RoomPlan 정렬이 180° 모호 | 모호하면 정렬하지 않고 메시 추정 구조로 대체 | 문·창이 보이도록 촬영 |
| 구조에서 벗어난 큰 벽 곡면/경사 | 평면 스냅이 5cm 이내만 보정(그 이상은 보존) | 허용치 밖 정점은 건드리지 않음 | — |
| 가려진 면(가구 뒤·천장 일부) | 텍스처 빈 곳 | 회색+마스크, '미관측 강조' 토글, 만들어 채우지 않음 | 추가 촬영 |
| 실내 한쪽 면만 아는 외벽 | 외벽 두께·외관 불확실 | CONFIG_DEFAULT/MEASURED(마주보는 벽 간격) 구분, "외관/벽두께 일부 추정" 배너, 승인 전 REVIEW_REQUIRED | BIM/실측 두께 입력 |
| LiDAR 없는 기기 | 깊이 없음 | 앱이 공간 스캔 시작을 막음(깊이 필수) | LiDAR 기기 사용 |
| 열·메모리 압박 | 촬영 중단 | 앱이 자동 일시정지(`thermalState≥serious`), 큐 보존 | 식힌 뒤 재개 |
| 대용량 업로드 중 네트워크 끊김 | 프레임 누락 | 청크 재개(offset)·sha256 검증·idempotency 키, 앱 재시작 후 큐 복구 | 자동 재시도 |
| 재구성 서버 재시작 | 진행 중 잡 소실 | 상태는 DB에 남고 `FAILED`/재요청 가능(프레임 원본 보존) | 재구성 재요청 |
| AI 모델 파일 없음 | 사람 마스크 비활성 | 조용히 꺼지고 나머지 동작(리포트에 `semanticMask.model=false`) | `tools/fetch_models.sh` |
