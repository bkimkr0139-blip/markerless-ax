# GROUND_TRUTH.md — 실측(Ground Truth) 캠페인 계획과 실기기 검증 항목

**현재 상태: 실측은 아직 하지 않았다.** 이 저장소의 모든 정확도 수치는 합성 장면 기준이며 *측량급 정확도를 주장하지 않는다*
(`docs/ACCEPTANCE.md`, `tools/twin_bench.py`). 이 문서는 실기기에서 반드시 확인해야 할 가정과, 실측 절차·판정 기준을 정한다.

## 1. 반드시 실기기로 확인할 가정 (틀리면 오차가 생긴다)
| # | 가정 | 확인 방법 | 틀릴 때 영향 |
|---|---|---|---|
| 1 | 픽셀 중심 = 인덱스+0.5, cx/cy는 좌상단 모서리 기준 (`camera.py`) | 평평한 벽 앞에서 깊이 점들의 평면 잔차를 +0.5/0 두 규약으로 비교 | 3m에서 최대 ~1cm 번짐·이중 표면 |
| 2 | depth 해상도 = RGB 해상도 비율 환산으로 intrinsics 대응 (`Frame.K_depth`) | 코너 모서리를 RGB·depth에서 같은 위치로 투영해 비교 | 텍스처 어긋남 |
| 3 | `sceneDepth` confidence 0/1/2 의미, 거리 한계(≈5m), 유리·검은 면 무효 | 반사·유리·검은 물체 앞에서 무효 비율 기록 | 구멍·가짜 표면 |
| 4 | RoomPlan 구조(별도 패스)와 RGB-D 세션의 정렬(`align_prior_to_mesh`)이 잔차 12cm 이내 | 직사각 방·L형 방·문 있는/없는 방 | 모호 → 메시 추정으로 대체(안전), 오정렬 → 구조 어긋남 |
| 5 | ARKit 재위치 인식 후 세션 좌표 ≈ 공간 좌표 | 월드맵 복원 전후 같은 코너 좌표 비교 | 병합 실패/이중 벽 |
| 6 | 한 번에 촬영한 방에서 포즈 드리프트가 cm 이내 | 시작점으로 돌아와 같은 코너 위치 비교(루프 클로저 오차) | 벽이 겹겹이 번짐 (합성 기준 ±1cm → 층 ~14mm) |
| 7 | iPhone 발열·메모리: 5분 연속 촬영에서 프레임 누락 없음 | 온도/`thermalState`·프레임 수 로그 | 촬영 중단 |

## 2. 장비·기준
- 기준 치수: 레이저 거리계(±1.5mm) 또는 토탈스테이션. 방마다 최소 **벽 길이 4개·층고·문 폭/높이·대표 사물 3개의 치수**.
- 기준점: 방 모서리 4개 + 바닥 표식 3점(스티커) — 스캔 메시와 측정값을 같은 좌표로 비교.
- 대상: **크기·형상이 다른 방 3개**(예: 소형 기계실, 직사각 사무실, L형/복도), 시설·사물 **5종 이상**.
- 각 방 5회 재방문(가구 위치 일부 변경 포함).

## 3. 지표와 합격선(초안)
| 지표 | 계산 | 초안 목표 |
|---|---|---|
| 벽 위치 오차 | 스캔 평면 vs 측정 평면 거리 | 중앙값 ≤ 3cm, p95 ≤ 6cm |
| 치수 오차 | 방 폭/길이/층고, 문 폭/높이 | ≤ 2% 또는 ≤ 5cm |
| 커버리지 | 면적 기준(`/coverage`) vs 수동 레퍼런스 | 접근 가능 표면 ≥ 85% |
| 텍스처 | 시각 감사(색 이음매·번짐·가림 오투영) | 심각 결함 0건 |
| 병합 | 5회 재방문 후 표면 이중화·균열 | 없음 |
| 정렬 모호 | 대칭 방에서 잘못 확정한 비율 | **0%** (모호하면 거부) |
| CAD 치환 | 오확정(다른 부품으로 승인) | **0건** |
측량급 공차 판정에 쓰려면 별도로 `docs/COORDINATE.md`의 BIM Shared Coordinates 보정과 불확실성 모델 회귀가 필요하다.

## 4. 기록 양식
`ground-truth/` 폴더에 방별 CSV: `room, item, measured_m, scanned_m, error_m, method, operator, date, device, build`.
측정 때마다 `tools/twin_bench.py`의 합성 결과와 나란히 비교해 합성↔실측 격차를 추적한다.
